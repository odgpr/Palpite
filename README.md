# Palpite

Jogo de adivinhar palavras em português com visual inspirado no Windows XP.

- **Clássico**: 1 palavra de 5 letras, 6 tentativas
- **Dupla**: 2 palavras ao mesmo tempo, 7 tentativas
- **Quádrupla**: 4 palavras ao mesmo tempo, 9 tentativas

As partidas são infinitas e seguem uma ordem fixa: a partida 1 tem as mesmas palavras para todo mundo, então dá para jogar junto com os amigos (use **Ir para a partida** nas estatísticas). Acentos e cedilha entram sozinhos.

Tudo fica num único arquivo, `index.html`, sem dependências nem servidor. Os sons são gerados pelo próprio navegador (Web Audio). As estatísticas ficam salvas no navegador de cada jogador.

Projeto independente, sem relação com a Microsoft. "Windows XP" é citado apenas como referência visual.

## Publicar

Funciona em qualquer hospedagem de site estático (Vercel, Netlify, GitHub Pages). No Vercel: **Add New → Project**, escolha este repositório e clique em **Deploy**, sem mudar configurações.
